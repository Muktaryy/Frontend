# What is CSS?

**CSS** stands for **Cascading Style Sheets**. It is used to control how a website looks.

## Why do we use CSS?
* **Better Design:** Websites made with only HTML look plain and boring. CSS turns them into modern, nice-looking, and easy-to-use websites.
* **Full Visual Control:** It lets you change:
  * **Colors** (color palettes)
  * **Size and Position** of items on the page
  * **Text Style (Typography)** like font type and thickness (font weight)
* **Animations:** You can add movement and animations to make the website feel alive and fun to use.
* **Layouts & Mobile Support:** Using tools like **CSS Grid** and **Flexbox**, you can build complex page layouts and make your site **responsive** (meaning it automatically adjusts to fit phones, tablets, and computers).
